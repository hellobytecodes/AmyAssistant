# 🟣 Amy — دستیار صوتی هوش مصنوعی شخصی

یک دستیار صوتی مثل Jarvis که با **Gemini Live API** صحبت می‌کنه (صدای زنانه‌ی نیتیو، نه یک TTS جدا)،
با گفتن اسمش («Amy») فعال می‌شه، و روی کل سیستمت اختیار کامل داره: باز کردن فایل و برنامه، ساختن
پوشه، جستجوی فایل توی کل کامپیوتر، اجرای هر دستور ترمینال، دیدن صفحه‌نمایش، کنترل صدا،
خاموش/روشن/خواب کردن سیستم، و مدیریت پردازش‌ها — پشت یک رابط گرافیکی شیشه‌ای انیمیشنی.

## ✨ ویژگی‌ها

| ویژگی | توضیح |
|---|---|
| 🎙️ گفتگوی صوتی زنده | صدای طبیعی و کم‌تاخیر مستقیماً از مدل Gemini (نه TTS جداگانه) |
| 👂 Wake word | با گفتن «Amy» (یا «ایمی») فعال می‌شه — بدون نیاز به PyAudio |
| 🖥️ کنترل کامل سیستم | اجرای هر دستور ترمینال، باز کردن برنامه/فایل/پوشه، خواندن/نوشتن/جابه‌جایی/حذف فایل |
| 📂 ساخت پوشه و جستجوی فایل | «Amy یه پوشه‌ی جدید بساز» / «Amy دنبال فایل رزومه‌م بگرد» در کل کامپیوتر |
| 🔊 کنترل صدا | زیاد/کم/میوت کردن صدای سیستم با صدا |
| ⚡ کنترل روشن/خاموش | خاموش کردن، ری‌استارت، یا خواب کردن سیستم (با تایید صریح) |
| 🧠 مدیریت پردازش‌ها | دیدن برنامه‌های در حال اجرا و بستن اجباری‌شون |
| 👁️ بینایی صفحه | اسکرین‌شات می‌گیره و درباره‌ی چیزی که روی صفحه‌ست صحبت می‌کنه |
| 🎨 رابط گرافیکی شیشه‌ای | پنجره‌ی بدون‌کادر، شفاف، با یک اورب نورانی که با صدا واکنش نشون میده |
| 🔇 ضد اکو | وقتی Amy داره جواب می‌ده میکروفون خودکار قطع می‌شه و بعد از تموم شدن حرفش خودش دوباره باز می‌شه (وضعیت بالا: «Speaking… (mic off)» / «Listening… (mic on)») |
| 🤖 هر کاری | اگه ابزار مخصوصی نباشه، Amy با ترمینال، اسکریپت پایتون، مرورگر، یا کیبورد/ماوس + دیدن صفحه خودش راهی پیدا می‌کنه |
| 🔒 ایمنی | کارهای معمولی بدون پرسیدن انجام می‌شن. فقط کارهای خطرناک (حذف، کشتن برنامه، خاموش/ری‌استارت، بازنویسی فایل، دستورهای ریسکی) اول **با صدا** ازت تایید می‌گیرن؛ فقط «آره/بله/باشه/تایید» خودت (نه مدل، نه متنی که روی صفحه‌ست) اجازه می‌ده. دستورات مخرب مثل `rm -rf /` همیشه مسدودن |

## 📁 ساختار پروژه

```
amy_assistant/
├── main.py                   # نقطه‌ی شروع برنامه

├── requirements.txt

│   ├── gemini_live_client.py # اتصال زنده به Gemini + تعریف همه‌ی ابزارها

├── system/
│   └── system_control.py     # ترمینال، فایل، پوشه، جستجو، صدا، پاور، پردازش، اسکرین‌شات
```

## ⚡ نصب و راه‌اندازی

### ۱. کلید API رایگان بگیر و مستقیم توی سورس بذار
از [Google AI Studio](https://aistudio.google.com/apikey) یک کلید Gemini رایگان بساز، بعد
فایل `config.py` رو باز کن و این خط رو پیدا کن:

```python
GEMINI_API_KEY = "PASTE_YOUR_GEMINI_API_KEY_HERE"
```

و کلیدت رو به جای متن داخل گیومه بذار. دیگه نیازی به `export` یا متغیر محیطی نیست.

> ⚠️ چون کلید مستقیم توی فایل می‌مونه، این فولدر رو جایی پابلیک (مثل گیت‌هاب عمومی) آپلود نکن.

### ۲. وابستگی‌ها رو نصب کن

```bash
cd amy_assistant
pip install -r requirements.txt
```

دیگه از **PyAudio** استفاده نمی‌شه — همه‌چیز روی `sounddevice` ساخته شده که روی هر سه سیستم‌عامل
با یک `pip install` ساده و بدون نیاز به کامپایلر نصب می‌شه.

### ۳. اجرا کن

```bash
python main.py
```

پنجره‌ی شیشه‌ای باز می‌شه، بگو **«Amy»** و بعد ازش هرچی خواستی بخواه — مثلاً:
- «Amy، مرورگر کروم رو باز کن»
- «Amy، توی کل کامپیوترم دنبال فایل‌های اسمشون invoice بگرد»
- «Amy، یه پوشه‌ی جدید به اسم پروژه‌ها توی دسکتاپ بساز»
- «Amy، ببین روی صفحه‌ام چی هست»
- «Amy، صدای سیستم رو زیاد کن»
- «Amy، وضعیت باتری و رم رو بگو»
- «Amy، برنامه‌ی فلان رو ببند»
- «Amy، دستور پینگ گوگل رو اجرا کن»
- «Amy، سیستم رو خاموش کن» (ازت تایید صوتی می‌خواد قبل از اجرا)

## 🛠️ چی درست شد؟

- **اکو / گیج شدن دستیار:** صدای خود Amy از اسپیکر وارد میکروفون می‌شد و به‌عنوان حرف تو ثبت می‌شد. حالا میکروفون موقع حرف زدنش قطعه (با `MUTE_MIC_WHILE_AMY_SPEAKS`). دکمه‌ی Talk/Stop دستی سر جاشه. اگه هدفون داری و می‌خوای وسط حرفش بپری، این گزینه رو `False` کن.
- **هویت:** Amy همیشه می‌گه اسمش Amy و دستیار کامپیوتر شماست، و سازنده‌اش سلمان آذرم (کلاس ۱۲ کامپیوتر) هست — تنظیمش توی `config.py` (`CREATOR_*`).
- **قابلیت‌ها:** ابزارهای جدید: اجرای کد پایتون، باز کردن لینک/جستجوی وب، کلیپ‌بورد، کیبورد و ماوس، تاریخ/ساعت. سیستم‌پرامپت حالا سیستم‌عامل، مسیر Desktop و … رو به مدل می‌گه.
- **باگ‌ها:** پخش صدا دیگه کل برنامه رو فریز نمی‌کنه؛ دیالوگ تایید روی ترد درست Qt باز می‌شه؛ ثبت گفتگو به‌صورت خط کامل (نه تکه‌تکه) و راست‌به‌چپ برای فارسی؛ «ایمیل» دیگه Amy رو بیدار نمی‌کنه؛ «Amy, open Chrome» دستورش گم نمی‌شه؛ فایل‌های فارسی UTF-8 خونده/نوشته می‌شن؛ kill_process دیگه خود Amy رو نمی‌کشه؛ حذف پوشه‌های حیاتی ممکن نیست؛ گفتگو بعد از `SESSION_IDLE_TIMEOUT` ثانیه سکوت خودکار بسته می‌شه و دوباره منتظر اسمش می‌مونه؛ دکمه Stop واقعاً سشن رو می‌بنده.

## 🪟 بستن پنجره‌ها (مثلاً درایو C)

پنجره‌ی هر پوشه (مثل C:) بخشی از `explorer.exe` هست که خودش تسک‌بار و دسکتاپ رو هم اجرا می‌کنه؛ پس «کشتن پردازش» اشتباه بود. حالا بستن = `close_window` (مثل زدن ضربدر همون پنجره، با عنوان یا اسم برنامه) و برای مطمئن شدن از عنوان `list_windows`. `kill_process` فقط برای برنامه‌ی هنگ‌کرده و آخرین راهه، با تایید صوتی، و روی `explorer.exe`، پردازش‌های سیستمی و خود Amy کار نمی‌کنه. روی لینوکس برای این قابلیت `wmctrl` لازمه.

## 🔧 شخصی‌سازی

همه‌چیز توی `config.py` قابل تغییره:
- `CONFIRM_METHOD` — `"voice"` (تایید با صدا) یا `"dialog"` (پنجره‌ی Yes/No)؛ `RISKY_COMMAND_WORDS` — چه دستوراتی «خطرناک» حساب بشن
- `MUTE_MIC_WHILE_AMY_SPEAKS` / `ECHO_TAIL_SECONDS` — قطع خودکار میکروفون موقع جواب دادن
- `SESSION_IDLE_TIMEOUT` — بسته شدن خودکار گفتگو بعد از سکوت
- `ALLOW_INPUT_CONTROL` — کنترل کیبورد/ماوس
- `GEMINI_VOICE` — صدای مدل (پیش‌فرض `Aoede`، یک صدای زنانه‌ی طبیعی؛ گزینه‌های دیگه: `Kore`, `Puck`, `Charon`)
- `WAKE_WORDS` — کلمات فعال‌سازی
- `ACCENT_COLOR` / `ACCENT_COLOR_2` — رنگ‌های رابط گرافیکی
- `ALLOW_POWER_ACTIONS` / `ALLOW_PROCESS_CONTROL` — روشن/خاموش کردن قابلیت خاموش‌کردن سیستم و بستن پردازش‌ها
- `FILE_SEARCH_MAX_RESULTS` / `FILE_SEARCH_TIMEOUT` — محدودیت جستجوی فایل در کل سیستم

## ⚠️ نکته‌ی مهم درباره‌ی مدل Live

مدل‌های Live API گوگل مدام آپدیت می‌شن و پیش‌نمایش‌های قدیمی از رده خارج می‌شن. اگه با خطای
مدل ناموجود (404) روبه‌رو شدی، جدیدترین اسم مدل native-audio رو از
[مستندات Live API](https://ai.google.dev/gemini-api/docs/live-api) بگیر و توی
`GEMINI_LIVE_MODEL` در `config.py` جایگزین کن.
